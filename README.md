# EchoBridge
App for hearing reabilitation in patients with hearing loss

## Moduli
- `echobridge/`: app di riabilitazione uditiva (React + Vite).
- `gmail-voice-reader/`: **EchoBridge Mail**, estensione Chrome/Edge che legge ad alta voce le email di Gmail, le riassume in 3 punti e prepara risposte dettate a voce. Vedi [gmail-voice-reader/README.md](gmail-voice-reader/README.md).
